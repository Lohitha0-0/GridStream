\# GridStream



A Real-Time Smart Meter Monitoring System built using Python and Apache Kafka.



\## Project Overview



GridStream simulates smart meters that continuously publish electricity consumption readings to an Apache Kafka topic.



A Kafka consumer processes these readings, calculates rolling averages for each meter, and identifies potential overload conditions.

\- Python

\- Apache Kafka

\- Docker
